# TraceForge 
### Developer Issue Tracking & Defect Management Platform

TraceForge is a full-stack web application designed to help developers organize software bugs, track issues, and manage defect resolution through a centralized interface.

Built with Next.js and TypeScript, the project focuses on creating a maintainable, type-safe foundation for developer productivity and issue management.

##  Features

- **Issue Tracking** — Centralize software defects and development issues.
- **Issue Management** — Organize issue information through a structured interface.
- **Type-Safe Development** — Leverage TypeScript for improved maintainability and fewer type-related errors.
- **Modern Web Architecture** — Use Next.js App Router to structure the application.
- **Responsive UI** — Build an interface designed to work across different screen sizes.

##  Getting Started

### Prerequisites

- Node.js 18 or later
- npm, yarn, pnpm, or bun
- Git

### 1. Clone the repository

```bash
git clone https://github.com/mrishikadhinakaran/TrackIT-BUG_TRACKER.git
cd TrackIT-BUG_TRACKER
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

### 4. Open the application

Navigate to [http://localhost:3000](http://localhost:3000) in your browser.

The application will reload automatically as you make changes to the source code.
